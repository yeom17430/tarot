Tarot card image files can be placed here later.

Recommended path pattern:

- `/cards/back/tarot-back.webp`
- `/cards/major/00-the-fool.webp`
- `/cards/major/01-the-magician.webp`

The first implementation renders card faces with CSS so the app runs without external image assets.

Optional ambience and effect assets can be placed under:

- `/audio/card-select.mp3`
- `/audio/card-flip.mp3`
- `/audio/ambience.mp3`
