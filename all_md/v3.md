# 타로 결과 화면 디자인 개선 요구사항

## 1. 수정 목적

현재 결과 화면은 다음 문제가 있다.

1. 메인 제목의 한글 자간과 줄바꿈이 부자연스럽다.
2. 제목이 너무 길고 한 번에 크게 표시되어 답답해 보인다.
3. 전체 디자인이 약간 촌스럽고 올드한 느낌이 난다.
4. 달빛 느낌보다는 금색 오컬트 느낌이 강하다.
5. 몽환적이고 세련된 분위기가 부족하다.

이 화면을 더 세련되고 몽환적인 “달빛 타로 룸” 분위기로 개선한다.

---

## 2. 디자인 방향

원하는 분위기:

- 달빛
- 몽환적
- 차분함
- 신비로움
- 부드러운 보랏빛
- 은은한 실버빛
- 안개가 낀 밤
- 세련된 고급감

피해야 할 분위기:

- 촌스러운 점집 느낌
- 과한 금색 장식
- 두꺼운 그림자
- 과한 텍스트 발광 효과
- 긴 제목을 한 번에 크게 보여주는 구조

---

## 3. 메인 제목 구조 수정

현재 긴 문장을 한 번에 크게 보여주지 말고, 메인 제목과 서브 제목으로 나눈다.

예시:

메인 제목:
마음의 숨고르기가 필요한 순간

서브 제목:
나를 따뜻하게 다독이는 연애 흐름

규칙:
1. 메인 제목은 1~2줄 이내로 제한한다.
2. 서브 제목은 메인 제목 아래 보조 문장으로 배치한다.
3. 메인 제목과 서브 제목의 시각적 위계를 분명히 나눈다.
4. 너무 긴 문장은 강제로 예쁘게 줄바꿈되도록 최대 너비를 제한한다.

---

## 4. 타이포그래피 수정

### 메인 제목
- 한글 가독성이 좋은 세리프 계열 사용
- 지나치게 장식적인 폰트는 피한다
- 자간은 약간 좁게 조정한다
- 줄간격은 답답하지 않게 조정한다

추천 스타일:
- letter-spacing: -0.02em ~ -0.04em
- line-height: 1.08 ~ 1.18
- font-weight: 700 또는 800
- max-width: 900px ~ 1100px
- text-align: center

### 보조 정보
예:
- TAROT CHAMBER
- 연애운 · 한 장 리딩
- 질문 문장

이 정보들은 메인 제목보다 훨씬 작고 정돈되게 보여야 한다.

---

## 5. 색상 수정

기존의 진한 금색 중심 구성 대신, 달빛 느낌의 보라/남색/실버 계열로 수정한다.

추천 색상:

```css
:root {
  --bg-top: #0b0820;
  --bg-mid: #171333;
  --bg-bottom: #0f1028;

  --text-primary: #f3eefb;
  --text-secondary: #c9c0dd;
  --text-muted: #a79fc0;

  --accent-moon: #d8dfff;
  --accent-lilac: #cdbdff;
  --accent-soft-gold: #d8cba3;

  --glow-moon: rgba(186, 198, 255, 0.24);
  --glow-purple: rgba(165, 125, 234, 0.16);
}
```

금색은 강조 포인트로만 아주 소량 사용한다.

---

## 6. 배경 수정

배경은 단순한 단색이 아니라 깊이감이 느껴지도록 구성한다.

반드시 포함할 요소:

1. 상단 뒤쪽의 흐릿한 달빛 glow
2. 좌우 또는 하단의 보랏빛 안개
3. 부드러운 radial gradient
4. 미세한 별 입자
5. 매우 약한 노이즈 텍스처
6. 어두운 남색~보라색 계열의 층감

배경은 다음 느낌이어야 한다.

- 달빛이 은은하게 스며드는 밤
- 안개가 살짝 낀 타로 룸
- 부드럽고 깊은 공간감
- 과하게 번쩍이지 않는 신비로운 분위기

---

## 7. 그림자와 글로우 수정

텍스트와 배경 효과는 부드럽고 은은해야 한다.

하지 말 것:
- 두꺼운 검은 그림자
- 강한 외곽 발광
- 촌스러운 노란 glow

권장:
- 부드러운 blur shadow
- 은은한 보라/달빛 계열 glow
- 투명도가 낮은 soft shadow

예시:
```css
text-shadow:
  0 2px 8px rgba(0, 0, 0, 0.24),
  0 0 22px rgba(196, 189, 255, 0.08);
```

---

## 8. 레이아웃 수정

현재 텍스트가 화면에 꽉 차 보이면 안 된다.

수정 방향:
1. 메인 콘텐츠의 최대 너비를 제한한다.
2. 요소 간 세로 여백을 충분히 둔다.
3. 화면 중앙 정렬은 유지하되 답답하지 않게 한다.
4. 제목, 메타 정보, 질문 문장을 카드처럼 묶거나 부드러운 패널 위에 배치할 수 있다.
5. 전체 높이에 여유를 주어 숨 쉴 공간이 느껴지게 한다.

추천:
- max-width: 1100px
- padding-top 여유 확대
- 섹션 간 간격 확대

---

## 9. 질문 문장 스타일 수정

현재 질문 문장은 메인 제목과 분위기가 살짝 충돌할 수 있다.

수정 방향:
- 질문 문장은 더 작고 차분하게
- 너무 노란색 강조는 피한다
- 살짝 라일락 또는 은은한 아이보리 톤 사용
- 인용문 형태는 유지 가능하지만 과하지 않게

예시:
```css
color: var(--accent-soft-gold);
opacity: 0.92;
font-size: 1.05rem;
line-height: 1.6;
```

---

## 10. 최종 분위기 기준

결과 화면은 아래 느낌을 목표로 한다.

- 달빛 아래서 조용히 결과를 읽는 느낌
- 감성적이지만 유치하지 않은 느낌
- 세련되고 몽환적인 타로 리딩 화면
- 부드러운 보랏빛과 실버빛 중심
- 과하지 않은 고급감

---

## 11. 구현 지시

현재 결과 화면 컴포넌트와 관련 CSS를 확인하고 다음 작업을 수행한다.

1. 메인 제목 문장을 메인/서브 구조로 재정리한다.
2. 제목 자간과 줄간격을 수정한다.
3. 한글 디스플레이 타이포그래피를 더 자연스럽게 조정한다.
4. 긴 제목이 예쁘게 줄바꿈되도록 최대 너비를 제한한다.
5. 배경을 달빛 + 안개 + 몽환적 gradient 구조로 수정한다.
6. 색상 팔레트를 보라/남색/실버 중심으로 조정한다.
7. 금색은 포인트 정도로만 사용한다.
8. 텍스트 그림자와 glow를 더 부드럽게 수정한다.
9. 전체 레이아웃 여백을 재조정한다.
10. 결과 화면이 촌스럽지 않고 세련되게 보이도록 전체 스타일을 다듬는다.
11. PC와 모바일 모두에서 타이틀 줄바꿈이 어색하지 않은지 확인한다.
12. `npm run build`로 스타일 변경 후 오류가 없는지 확인한다.

코드 일부만 예시로 보여주지 말고 실제 프로젝트 파일을 수정한다.
