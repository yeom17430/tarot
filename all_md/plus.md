# AI 타로 해석 말투 및 종합 리딩 개선 요구사항

## 1. 수정 목적

현재 타로 해석 결과가 다음과 같은 문제가 있다.

1. 문장이 지나치게 딱딱하다.
2. 거의 모든 문장이 `~로 해석할 수 있습니다` 형태로 반복된다.
3. 카드의 키워드를 단순히 나열하는 느낌이 강하다.
4. 카드별 설명은 있지만 카드 전체를 연결한 종합 해석이 부족하다.
5. 사용자의 질문과 카드 해석이 충분히 연결되지 않는다.
6. 결과가 AI가 자동 생성한 설명문처럼 느껴진다.
7. 사용자를 직접 바라보며 이야기해주는 느낌이 부족하다.
8. 카드별 해석 내용이 서로 비슷한 문장 구조를 사용한다.

이를 개선하여 사용자가 실제 타로 리더에게 편안하게 이야기를 듣는 것처럼 느끼도록 한다.

---

# 2. 원하는 전체 말투

타로 해석은 너무 격식 있거나 사무적인 말투가 아니라, 친근하고 부드러운 존댓말을 사용한다.

친구처럼 지나치게 가볍게 말하지는 않지만, 사용자의 이야기를 잘 들어주는 사람처럼 편안한 말투를 사용한다.

## 원하는 분위기

- 따뜻함
- 친근함
- 차분함
- 신뢰감
- 자연스러운 존댓말
- 부담 없는 대화
- 사용자의 감정을 존중하는 느낌
- 실제 사람이 설명해주는 듯한 흐름

## 피해야 하는 분위기

- 보고서 같은 말투
- 교과서 같은 말투
- 상담 기록 같은 말투
- 점술가가 미래를 단정하는 말투
- 지나치게 감성적인 문장
- 지나치게 친구처럼 반말에 가까운 표현
- 사용자의 감정을 대신 단정하는 표현
- 같은 문장 종결 표현의 반복

---

# 3. 권장 말투 예시

## 너무 딱딱한 기존 형태

```text
절제 역방향 카드는 현재 상황에서 속도를 조절하고 놓치고 있는 부분을 다시 살펴보라는 메시지로 해석할 수 있습니다.
```

## 개선된 형태

```text
절제 카드가 역방향으로 나온 걸 보면, 지금은 마음과 상황의 균형이 조금 흔들리고 있는 것 같아요. 서둘러 답을 정하기보다는 내가 무엇 때문에 불안한지부터 천천히 살펴보는 시간이 필요해 보여요.
```

---

## 너무 딱딱한 기존 형태

```text
세계 역방향 카드는 현재 상황에서 속도를 조절하고 놓치고 있는 부분을 다시 살펴보라는 메시지로 해석할 수 있습니다.
```

## 개선된 형태

```text
세계 카드가 역방향으로 나온 건, 관계가 완전히 끝났다는 뜻보다는 아직 정리되지 않은 감정이나 이야기가 남아 있다는 쪽에 가까워요. 서로가 기대하는 결론이 다르거나, 마지막 한 걸음을 망설이고 있을 수도 있어요.
```

---

## 너무 기계적인 기존 형태

```text
마법사 카드는 실행력, 재능, 집중, 기회의 흐름을 중심으로 살펴볼 수 있습니다.
```

## 개선된 형태

```text
마법사는 지금 관계를 움직일 수 있는 힘이 어느 정도 남아 있다는 걸 보여줘요. 다만 이 카드는 생각만 하기보다 어떤 방식으로든 표현하고 행동해야 흐름이 바뀐다고 말하는 카드이기도 해요.
```

# 4. 기본 문체 규칙

다음 문체 규칙을 반드시 적용한다.

1. 모든 답변은 자연스러운 한국어 존댓말로 작성한다.
2. `~합니다`만 반복하지 말고 다음 표현을 자연스럽게 섞는다.

```text
~로 보여요.
~일 수 있어요.
~에 가까워 보여요.
~라는 마음이 느껴져요.
~를 말해주는 카드예요.
~를 한 번 살펴볼 필요가 있어 보여요.
~라고 볼 수도 있어요.
~가 중요해 보여요.
~일 가능성이 있어요.
~를 서두르지 않는 편이 좋아요.
```

3. 한 문단 안에서 같은 종결 표현을 반복하지 않는다.
4. `해석할 수 있습니다`라는 문장을 과도하게 사용하지 않는다.
5. 한 카드의 키워드를 그대로 나열하지 않는다.
6. 키워드를 실제 상황에 맞는 자연스러운 문장으로 풀어서 설명한다.
7. 사용자의 질문을 중간중간 자연스럽게 언급한다.
8. 사용자를 `당신`이라고 반복해서 부르지 않는다.
9. 필요할 때는 `지금 마음을 보면`, `현재 상황에서는`, `이번 관계에서는`과 같은 표현을 사용한다.
10. 문장이 지나치게 길어지지 않도록 2~4문장 단위로 나눈다.
11. 과장된 시적 표현을 반복하지 않는다.
12. 운명, 숙명, 필연과 같은 표현은 최소화한다.

# 5. 사용자에게 말을 거는 방식

사용자에게 직접 말을 걸듯 작성하되, 부담스럽게 친한 척하지 않는다.

## 권장 표현

```text
지금 가장 먼저 보이는 건...
이 카드 조합에서는...
현재 마음을 보면...
조금 조심해서 봐야 할 부분은...
다만 여기서 중요한 건...
너무 부정적으로만 볼 필요는 없어요.
당장 결론을 내리기보다는...
한 번 마음을 정리해보는 게 좋아 보여요.
```

## 피해야 하는 표현

```text
친구야
솔직히 말해서
완전 잘될 것 같아
무조건 기다려
그 사람은 널 사랑해
내가 보기에 100%야
너는 지금 이래
상대방은 반드시 이렇게 생각해
```

사용자와 가까운 느낌은 주되, 반말이나 지나치게 가벼운 인터넷 말투는 사용하지 않는다.

# 6. 전체 종합 해석 필수 추가

카드별 해석만 출력하지 말고 반드시 카드 전체를 연결한 종합 해석을 제공한다.

전체 종합 해석은 가장 중요한 영역으로 취급한다.

## 종합 해석에서 포함할 내용

1. 전체 카드가 보여주는 가장 큰 흐름
2. 사용자의 질문과 직접적으로 연결되는 내용
3. 카드들 사이의 공통점
4. 서로 충돌하는 카드가 있다면 그 의미
5. 현재 감정과 현실적인 상황
6. 가까운 흐름에서 바뀔 수 있는 부분
7. 사용자가 주의하면 좋은 점
8. 현실적으로 취할 수 있는 행동

## 종합 해석 작성 방식

단순히 카드를 한 장씩 다시 설명하지 않는다.

잘못된 예시:

```text
첫 번째 카드는 절제입니다.
두 번째 카드는 세계입니다.
세 번째 카드는 악마입니다.
따라서 관계를 살펴볼 필요가 있습니다.
```

올바른 예시:

```text
전체 흐름을 보면, 이 관계는 마음이 완전히 끝난 상태라기보다 서로 다른 속도로 감정을 정리하고 있는 모습에 가까워 보여요. 절제와 세계가 모두 역방향으로 나온 점을 보면, 두 사람 모두 관계를 깔끔하게 마무리하거나 다시 시작할 준비가 충분하지 않을 수 있어요.

여기에 악마 카드가 더해지면서 미련이나 집착, 상대방의 반응을 계속 확인하고 싶은 마음이 관계를 더 어렵게 만들 수 있다는 점도 보여요. 반면 마법사와 은둔자는 감정만 따라가기보다 내가 할 수 있는 행동과 혼자 생각을 정리하는 시간이 모두 필요하다고 말하고 있어요.

따라서 지금은 상대방의 마음을 빨리 확인하려 하기보다, 내가 이 관계에서 정말 원하는 것이 재회인지, 미련을 해소하는 것인지 먼저 정리해보는 게 좋아 보여요. 연락을 시도한다면 무거운 감정 표현보다 가볍고 부담 없는 방식이 더 잘 맞을 수 있어요.
```

# 7. 카드별 해석 개선 규칙

각 카드별 해석은 다음 구조를 따른다.

```text
카드 위치 제목
→ 카드가 현재 위치에서 의미하는 핵심
→ 사용자의 질문과 연결되는 설명
→ 주의할 점 또는 가능성
```

예시:

```text
나의 현재 마음 - 절제 역방향

지금 마음속에서는 감정의 균형이 조금 흔들리고 있는 것 같아요. 상대방과의 관계를 차분하게 바라보고 싶으면서도, 한편으로는 빠르게 답을 확인하고 싶은 마음도 함께 있을 수 있어요. 이런 상태에서는 작은 반응에도 의미를 크게 부여할 수 있으니, 먼저 내 감정을 안정시키는 게 중요해 보여요.
```

카드 설명은 카드 데이터의 기본 키워드를 활용하되, 키워드를 그대로 복사하지 않는다.

잘못된 예시:

```text
절제 카드는 균형, 조화, 인내, 절제를 의미합니다.
```

개선된 예시:

```text
절제는 감정과 현실 사이의 균형을 말해주는 카드예요. 지금은 어느 한쪽으로 마음이 크게 치우치기보다, 내가 원하는 것과 실제 상황을 함께 살펴볼 필요가 있어 보여요.
```

# 8. 같은 설명 반복 금지

현재 결과처럼 서로 다른 카드에 동일한 문장을 사용하면 안 된다.

잘못된 예시:

```text
절제 역방향 카드는 속도를 조절하고 놓치고 있는 부분을 다시 살펴보라는 메시지입니다.

세계 역방향 카드는 속도를 조절하고 놓치고 있는 부분을 다시 살펴보라는 메시지입니다.

별 역방향 카드는 속도를 조절하고 놓치고 있는 부분을 다시 살펴보라는 메시지입니다.
```

각 카드는 고유한 상징을 반영하여 다르게 설명한다.

예시:

```text
절제 역방향
→ 감정 균형의 흔들림, 지나친 조급함, 서로 다른 속도

세계 역방향
→ 마무리되지 않은 관계, 미완성된 감정, 결론을 내리지 못함

별 역방향
→ 기대가 약해짐, 자신감 부족, 희망을 확인하고 싶은 마음
```

Gemini 프롬프트에 다음 규칙을 반드시 넣는다.

```text
서로 다른 카드에 동일하거나 거의 동일한 해석 문장을 반복하지 마세요.
각 카드의 고유한 상징, 방향, 위치, 사용자의 질문을 반영하여 개별적으로 작성하세요.
```

# 9. 질문 중심 해석

카드 설명보다 사용자의 실제 질문이 중심이 되어야 한다.

예를 들어 질문이 다음과 같다면:

```text
그 사람과 다시 연락할 가능성이 있을까요?
```

단순히 카드 의미만 설명하지 말고 다음 내용을 연결한다.

- 연락 가능성을 완전히 단정하지 않는다.
- 상대방의 현재 상태로 볼 수 있는 흐름
- 사용자의 현재 마음
- 연락을 방해하는 요소
- 연락을 시도할 때 주의할 점
- 기다리는 것이 좋은지, 가볍게 행동하는 것이 좋은지
- 관계를 다시 볼 때 현실적으로 확인해야 할 부분

질문을 반복해서 그대로 복사하지 말고 자연스럽게 연결한다.

예시:

```text
다시 연락이 이어질 가능성이 완전히 닫혀 있다고 보기는 어려워요. 다만 현재 카드 흐름에서는 상대방 역시 감정을 정리하거나 혼자 생각할 시간이 필요한 모습이 강해서, 즉각적인 반응을 기대하면 오히려 마음이 더 지칠 수 있어요.
```

# 10. 카드 간 연결 해석

세 장 또는 일곱 장 리딩에서는 카드 간 연결 해석을 반드시 별도 항목으로 제공한다.

카드 간 연결 해석에서는 다음을 살펴본다.

- 비슷한 의미를 가진 카드
- 서로 반대되는 의미를 가진 카드
- 정방향과 역방향의 흐름
- 앞 카드가 뒤 카드에 주는 영향
- 반복되는 감정이나 행동
- 상황이 막히는 원인
- 흐름이 바뀔 수 있는 지점

예시:

```text
절제와 세계가 모두 역방향으로 나온 점은 관계의 속도와 마무리 방식이 서로 맞지 않았을 가능성을 보여줘요. 한쪽은 답을 빨리 확인하고 싶고, 다른 쪽은 아직 생각을 정리하지 못했을 수 있어요.

하지만 마법사 정방향은 이 관계에서 아무것도 할 수 없다는 뜻은 아니에요. 대화 방식이나 접근 방식을 바꾸면 지금과 다른 흐름이 만들어질 여지는 있어 보여요.
```

# 11. 현실적인 조언 강화

결과에는 반드시 현실적인 조언이 포함되어야 한다.

조언은 막연한 문장으로 끝내지 않는다.

피해야 할 예시:

```text
마음을 잘 살펴보세요.
긍정적으로 생각하세요.
기다리면 좋은 일이 생길 것입니다.
```

권장 예시:

```text
지금 바로 감정을 길게 전달하기보다는, 연락을 한다면 안부를 묻는 정도의 짧고 부담 없는 방식이 더 좋아 보여요. 상대방의 반응이 늦더라도 그 자체를 거절로 단정하지 말고, 일정한 거리를 두고 상황을 지켜보는 편이 좋겠어요.
```

조언은 다음과 같은 형태로 구체화한다.

- 지금 하면 좋은 행동
- 지금 피하면 좋은 행동
- 감정을 정리하는 방법
- 상대방에게 접근하는 방법
- 결정을 미루는 것이 좋은 상황

# 17. Fallback 해석도 같은 말투로 수정

Gemini API 키가 없거나 API 요청이 실패했을 때 사용하는 fallback 해석도 현재처럼 기계적인 문장을 사용하면 안 된다.

잘못된 fallback 예시:

```text
절제 역방향 카드는 현재 상황에서 속도를 조절하고 놓치고 있는 부분을 다시 살펴보라는 메시지로 해석할 수 있습니다.
```

개선된 fallback 예시:

```text
절제 카드가 역방향으로 나온 걸 보면, 지금은 감정과 현실 사이의 균형이 조금 흐트러져 있을 수 있어요. 상대방의 반응을 빨리 확인하고 싶은 마음이 있더라도, 먼저 내가 무엇 때문에 조급해졌는지 살펴보는 게 좋아 보여요.
```

fallback에서도 카드마다 동일한 문장을 반복하지 않는다.

카드별 정방향과 역방향 의미를 카드 데이터에 충분히 저장하고, 선택 위치와 질문 주제에 맞게 문장을 조합한다.

# 18. 주제별 말투와 해석 방향

## 연애운

- 감정을 단정하지 않는다.
- 상대방의 마음을 사실처럼 말하지 않는다.
- 소통 방식, 감정 속도, 관계의 균형을 중심으로 본다.
- 재회 여부만 강조하지 않는다.
- 사용자의 감정 보호와 현실적 행동을 함께 제안한다.

## 재물운

- 투자 수익을 보장하지 않는다.
- 금전적 성공을 확정하지 않는다.
- 소비 습관, 기회, 위험 관리, 준비 상태를 중심으로 본다.
- 투자 판단은 전문가와 현실 정보를 참고하도록 안내한다.

## 진로운

- 취업이나 합격을 확정하지 않는다.
- 사용자의 강점, 불안 요소, 준비 상태, 행동 방향을 연결한다.
- 구체적으로 점검할 부분을 제안한다.

## 학업운

- 성적이나 합격을 단정하지 않는다.
- 집중력, 학습 습관, 불안, 준비 계획을 중심으로 설명한다.
- 실천 가능한 공부 방향을 제안한다.

## 인간관계

- 상대방의 의도를 확정하지 않는다.
- 오해, 거리감, 소통 방식, 경계 설정을 중심으로 본다.
- 무조건 관계를 유지하거나 끊으라고 말하지 않는다.

## 오늘의 운세

- 하루에 발생할 사건을 단정하지 않는다.
- 오늘의 감정 흐름, 주의할 행동, 활용할 기회를 중심으로 설명한다.
- 짧고 실용적인 조언을 제공한다.

# 19. 프론트엔드 결과 화면 개선

결과 화면은 현재처럼 텍스트를 단순히 위에서 아래로 나열하지 않는다.

## 리딩 제목

사용자의 질문과 전체 카드 흐름을 반영한 자연스러운 제목을 표시한다.

예시:

```text
서두르기보다 서로의 속도를 살펴볼 때
```

## 전체 종합 해석

가장 먼저 충분한 분량의 전체 해석을 보여준다.

카드별 해석보다 시각적으로 더 강조한다.

추천 디자인:

- 금색 제목
- 읽기 편한 문단 간격
- 최대 너비 제한
- 어두운 반투명 패널
- 문단 사이 충분한 여백

---

## 핵심 흐름 한눈에 보기

4개의 작은 카드 또는 박스로 표시한다.

```text
현재 흐름
가장 큰 장애물
열려 있는 가능성
지금 필요한 태도
```

---

## 카드별 해석

카드별로 다음 정보를 표시한다.

- 카드 이미지
- 카드 위치
- 카드 이름
- 정방향 또는 역방향
- 자연스러운 카드 해석

카드별 해석 사이의 여백을 충분히 준다.

---

## 카드 간 연결

카드들이 서로 어떤 흐름을 만드는지 별도 영역으로 보여준다.

---

## 현실적인 조언

단순한 위로가 아니라 실제로 적용할 수 있는 행동을 보여준다.

---

## 지금 기억하면 좋은 한마디

결과 가장 아래에 짧고 따뜻한 문장을 표시한다.

예시:

```text
답을 서두르지 않아도 괜찮아요. 지금은 내 마음의 속도를 먼저 이해하는 게 더 중요할 수 있어요.
```

# 21. Codex 작업 지시

현재 Gemini 프롬프트, fallback 해석 로직, 결과 타입, 결과 화면을 모두 확인하고 다음 작업을 수행한다.

1. 기존의 딱딱한 문체를 제거한다.
2. 반복되는 `~로 해석할 수 있습니다` 문장을 제거한다.
3. 카드별로 동일한 fallback 문장이 출력되는 문제를 수정한다.
4. 카드의 고유한 정방향 및 역방향 의미를 반영한다.
5. 사용자의 질문과 각 카드를 직접 연결한다.
6. 전체 종합 해석을 충분한 분량으로 생성한다.
7. 핵심 흐름 한눈에 보기 영역을 추가한다.
8. 카드 간 연결 해석을 강화한다.
9. 현실적인 조언을 구체적으로 작성한다.
10. 말투를 따뜻하고 친근한 존댓말로 변경한다.
11. 너무 친구처럼 가볍거나 반말에 가까운 표현은 사용하지 않는다.
12. Gemini 응답 JSON 타입을 새로운 구조로 변경한다.
13. fallback 결과도 같은 JSON 구조를 사용하도록 수정한다.
14. 프론트엔드 결과 화면을 새로운 구조에 맞게 수정한다.
15. 기존 카드 선택, 셔플, 플립 애니메이션은 변경하지 않는다.
16. TypeScript 타입 오류를 해결한다.
17. API 키가 없는 상태와 있는 상태를 모두 테스트한다.
18. `npm run build`를 실행하여 빌드 오류를 확인한다.
