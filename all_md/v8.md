이전 수정으로 문제가 해결되지 않았습니다.

현재 “결과 이미지 복사”로 만든 이미지에서 7장의 카드 아래 설명이 다음처럼 한 줄로 이어 붙어 서로 겹칩니다.

예시:
현재 상황 과거의 영향긴 감정 또는 관계의 장애물도움이 되는 외부환경 미래의 흐름최종 조언

중요:
이 문제는 단순한 font-size나 줄 간격 문제가 아닙니다.
현재 카드 이미지 목록과 카드 포지션 설명 목록이 서로 분리된 DOM으로 렌더링되고 있는지 확인해주세요.

현재 증상으로 보아 다음과 같은 잘못된 구조일 가능성이 높습니다.

잘못된 구조 예시:

<div className="cards">
  {selectedCards.map((card) => (
    <img src={card.image} />
  ))}
</div>

<div className="position-labels">
  {positionLabels.map((label) => (
    <span>{label}</span>
  ))}
</div>

이 방식은 카드 이미지와 설명이 개별적으로 묶이지 않아서,
캡처 시 설명이 하나의 긴 텍스트 줄처럼 붙을 수 있습니다.

반드시 카드 이미지와 해당 카드의 설명을 같은 map 내부에서 하나의 item으로 묶어주세요.

원하는 구조:

<div className="capture-card-grid">
  {selectedCards.map((card, index) => (
    <div className="capture-card-item" key={card.id}>
      <div className="capture-card-image-wrap">
        <img
          src={card.image}
          alt={card.name}
          className={card.isReversed ? "reversed" : ""}
        />
      </div>

      <div className="capture-card-meta">
        <span className="capture-card-position">
          {positionLabels[index]}
        </span>

        <strong className="capture-card-name">
          {card.name}
        </strong>

        <span className="capture-card-orientation">
          {card.isReversed ? "역방향" : "정방향"}
        </span>
      </div>
    </div>
  ))}
</div>

핵심 요구사항:

1. 카드 이미지와 해당 포지션 설명을 같은 capture-card-item 안에 넣어주세요.
2. 카드 설명 목록을 별도의 공통 행으로 렌더링하지 마세요.
3. 카드마다 독립된 너비를 갖게 해주세요.
4. 각 카드 설명은 자신의 카드 폭 안에서만 줄바꿈되게 해주세요.
5. 7장 리딩 캡처에서는 한 줄 7칸으로 너무 좁게 만들지 말고 4칸 + 3칸 형태로 배치해주세요.
6. 원본 화면은 유지해도 되지만 캡처용 DOM은 별도로 생성해주세요.

캡처용 7장 레이아웃:
- 첫 번째 줄: 카드 4장
- 두 번째 줄: 카드 3장
- 두 번째 줄도 가운데 정렬

검증 항목:
1. 복사된 이미지에서 카드 7장이 4장 + 3장으로 배치되는지
2. 각 카드 아래 설명이 자기 카드 바로 아래에 표시되는지

7. npm run build가 성공하는지
