4. 사용자가 카드를 선택하고 공개하는 순간 카드가 Y축으로 자연스럽게 180도 회전하면서 앞면 이미지로 뒤집히는 3D flip 애니메이션을 적용해주세요.

필수 CSS 구조:

- 앞면: rotateY(180deg)
- 공개 상태의 내부 요소: rotateY(180deg)

5. 정방향과 역방향을 시각적으로 정확하게 표현해주세요.

카드를 뽑을 때 각 카드에 isReversed boolean 값이 저장되어 있어야 합니다.

정방향:
- 앞면 이미지를 정상 방향으로 표시

역방향:
- 카드가 공개된 뒤 앞면 이미지 전체를 정확히 180도 회전해서 표시
- 역방향이라고 이미지를 좌우 반전하거나 별도 이미지를 사용하지 말 것
- CSS transform: rotate(180deg)를 사용
- 카드 제목 글씨만 따로 돌리지 말고 이미지 전체가 상하 반전되어야 함

중요:
카드 flip의 rotateY와 역방향 rotateZ가 충돌하지 않도록 요소를 분리해주세요.

권장 구조:

<div className={`tarot-card ${isFlipped ? "is-flipped" : ""}`}>
  <div className="tarot-card-inner">
    <div className="tarot-card-back">
      <img src="/cards/78.png" alt="타로 카드 뒷면" />
    </div>

    <div className="tarot-card-front">
      <img
        src={card.image}
        alt={card.name}
        className={isReversed ? "reversed" : ""}
      />
    </div>
  </div>
</div>

권장 CSS 개념:

.tarot-card {
  perspective: 1200px;
}

.tarot-card-inner {
  width: 100%;
  height: 100%;
  position: relative;
  transform-style: preserve-3d;
  transition: transform 0.8s cubic-bezier(.2,.7,.2,1);
}

.tarot-card.is-flipped .tarot-card-inner {
  transform: rotateY(180deg);
}

.tarot-card-front,
.tarot-card-back {
  position: absolute;
  inset: 0;
  backface-visibility: hidden;
  -webkit-backface-visibility: hidden;
}

.tarot-card-front {
  transform: rotateY(180deg);
}

.tarot-card-front img.reversed {
  transform: rotate(180deg);
}

6. 역방향 여부는 카드 선택 시 한 번만 결정하고 이후 재렌더링되더라도 바뀌지 않게 해주세요.
