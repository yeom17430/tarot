# 로딩 화면 배경 디자인 개선 요구사항

## 1. 수정 목적

현재 로딩 화면의 가운데 콘텐츠 영역은 비교적 괜찮지만, 바깥 배경이 전체적으로 촌스럽고 무대 세트장 같은 느낌을 준다.

특히 다음 요소가 문제다.

1. 좌우의 줄무늬 커튼이 너무 직접적이고 올드하다.
2. 아래 양옆 촛불이 장식 이미지처럼 보여 세련되지 않다.
3. 달과 별 배경이 평면적이라 공간감이 부족하다.
4. 하단 바닥 느낌이 과장되어 보인다.
5. 전체적으로 “달빛 몽환감”보다 “테마형 점집 세트장” 느낌이 강하다.

이 화면을 더 세련되고 몽환적인 달빛 중심의 배경으로 수정한다.

---

# 2. 유지할 요소

다음 요소는 현재 방향이 괜찮으므로 유지하거나 큰 틀을 유지한다.

1. 중앙의 로딩 콘텐츠 박스 또는 패널
2. 가운데 원형 달 심볼
3. 메인 문구
4. 서브 문구
5. 전체적인 어두운 보라/남색 계열 분위기

---

# 3. 제거 또는 약화할 요소

다음 요소는 제거하거나 매우 약하게 수정한다.

1. 좌우의 강한 세로 줄무늬 커튼
2. 하단 양옆의 큰 촛불 오브젝트
3. 과하게 장식적인 무대 느낌
4. 직접적인 프레임 구조
5. 배경에서 너무 눈에 띄는 소품

---

# 4. 새로운 배경 방향

배경은 다음 키워드를 중심으로 재구성한다.

- 달빛
- 몽환적
- 차분함
- 안개
- 은은한 광원
- 깊은 남색
- 부드러운 보랏빛
- 조용한 타로 룸
- 고급스럽고 절제된 분위기

배경은 소품 중심이 아니라 “공기감과 빛” 중심으로 표현한다.

---

# 5. 구체적인 배경 구성

다음을 포함한다.

1. 전체 배경에 짙은 남색~보라색 그라데이션
2. 중앙 뒤쪽에 부드러운 달빛 glow
3. 화면 가장자리에 약한 vignette
4. 아주 부드러운 안개 또는 mist 레이어
5. 작은 별 입자
6. 은은한 보랏빛 광원 퍼짐
7. 필요하다면 달은 유지하되 훨씬 부드럽고 자연스럽게 배치

다음을 피한다.

1. 선명한 줄무늬
2. 무대 세트장 느낌
3. 촌스러운 장식 이미지
4. 과한 점집 느낌
5. 너무 많은 배경 오브젝트

# 6. 색상 방향

다음 색상 계열을 사용한다.

```css
:root {
  --bg-top: #090818;
  --bg-mid: #11122b;
  --bg-bottom: #171334;

  --glow-moon: rgba(200, 210, 255, 0.18);
  --glow-purple: rgba(143, 110, 214, 0.14);
  --mist: rgba(187, 176, 255, 0.06);

  --text-primary: #f5f0fb;
  --text-secondary: #c9c1de;
  --accent-soft-gold: #d9c89d;
  --accent-lilac: #cfc1ff;
}
```

금색은 최소한의 포인트로만 사용한다.

# 7. 커튼 처리 방식

현재처럼 줄무늬가 선명한 커튼은 제거한다.

대신 다음 중 하나를 선택한다.

1. 커튼을 완전히 제거한다.
2. 아주 흐릿한 벨벳 질감만 남긴다.
3. 좌우 가장자리에 매우 약한 어두운 패브릭 느낌만 넣는다.

사용자가 “커튼”을 명확하게 인식하기보다는,
배경의 가장자리가 자연스럽게 어두워지는 정도가 좋다.

---

# 8. 촛불 처리 방식

현재의 촛불은 제거하거나 매우 약하게 축소한다.

촛불을 유지해야 한다면 다음 규칙을 따른다.

1. 크기를 크게 줄인다.
2. 배경과 자연스럽게 섞이게 한다.
3. 하단 구석에서 아주 희미하게만 보이게 한다.
4. 장식 오브젝트처럼 튀지 않게 한다.

하지만 가장 권장되는 방향은 촛불을 아예 제거하고 광원과 안개만으로 분위기를 만드는 것이다.

---

# 9. 바닥 처리 방식

지금의 하단 바닥 느낌은 과장되거나 무대처럼 보이지 않게 수정한다.

대신 다음처럼 표현한다.

1. 중앙 아래쪽에 매우 흐릿한 타원형 그림자
2. 살짝 빛이 퍼진 안개층
3. 콘텐츠 패널 아래쪽의 공간감 정도만 표현

즉, “무대 바닥”처럼 보이지 않아야 한다.

---

# 10. 최종 목표

배경은 다음 느낌이 되어야 한다.

- 달빛 아래 조용히 타로 해석을 기다리는 밤
- 안개와 빛이 부드럽게 퍼지는 몽환적인 공간
- 세련되고 고급스럽지만 과하지 않은 오컬트 무드
- 가운데 메시지를 방해하지 않는 차분한 배경

즉, 배경은 눈에 띄는 장식이 아니라
가운데 콘텐츠를 더 돋보이게 만드는 조용한 무드 역할을 해야 한다.

---

# 11. 구현 지시

현재 로딩 화면 관련 컴포넌트와 CSS를 확인하고 다음 작업을 수행한다.

1. 좌우 줄무늬 커튼을 제거하거나 매우 약하게 수정한다.
2. 촛불 오브젝트를 제거하거나 아주 약하게 축소한다.
3. 하단 바닥 느낌을 단순화한다.
4. 배경을 달빛 + 안개 + 그라데이션 중심으로 재구성한다.
5. 중앙 콘텐츠가 더 돋보이도록 배경의 시각적 소음을 줄인다.
6. 별과 광원 효과를 더 세련되게 다듬는다.
7. 전체 배경이 촌스럽지 않고 몽환적으로 보이도록 재설계한다.
8. PC와 모바일 모두에서 배경이 과하지 않게 보이도록 조정한다.
9. build 오류가 없는지 확인한다.

코드 일부만 예시로 보여주지 말고 실제 프로젝트 파일을 수정한다.
