현재 타로 결과 페이지 자체는 정상적으로 보이지만,
하단의 "결과 이미지 복사" 버튼을 눌러 생성된 이미지에서만 카드 아래 텍스트가 서로 겹치는 문제가 있습니다.

즉, 일반 화면 레이아웃 문제가 아니라
html2canvas 또는 DOM 캡처 라이브러리로 결과 영역을 이미지로 변환할 때 발생하는 렌더링 문제입니다.

현재 버튼:
- 처음으로
- 결과 이미지 복사
- 다시 보기

"결과 이미지 복사" 버튼을 누르면
타로 결과 영역을 이미지로 캡처한 뒤 클립보드에 복사하고,
"타로 리딩 결과 이미지를 복사했습니다."라는 안내 문구가 표시됩니다.

문제 상황:
- 실제 브라우저 화면에서는 카드 7장과 카드 아래 설명이 정상적으로 보임
- 복사된 결과 이미지를 붙여넣으면 카드 아래의 역할 설명 문구들이 한 줄로 겹쳐 보임
- 특히 7장 리딩에서 긴 한글 포지션 문구가 각 카드 폭을 넘어 옆 텍스트와 겹침
- 캡처 과정에서 grid/flex 폭, 줄바꿈, 웹폰트 또는 transform이 정상 반영되지 않는 것으로 보임
